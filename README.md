# Prospi Live Overlay

eBaseball **프로야구 스피리츠 2026**을 하는 동안 화면 위에 **실시간 시청자 채팅**처럼 반응이 흘러나오게 하는 오버레이입니다.
홈런엔 채팅창이 터지고, 삼진엔 탄식이, 상대 팬은 가끔 반대편에서 끼어듭니다.

- 설치 없이 exe 하나로 실행 (portable)
- 게임 화면 글자 인식(OCR)과, 켜면 **싱글 경기 한정 게임 메모리 읽기**로 볼카운트·이닝·타석 결과를 알아냅니다
- 새 버전이 나오면 프로그램이 알려 주고 **자동으로 업데이트**합니다

## 다운로드

[Releases](../../releases/latest)에서 `ProspiLiveOverlay-x.y.z-portable.exe`를 받아 실행하면 끝입니다.

- Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행** (코드 서명 인증서가 없어서 뜨는 경고입니다)
- 브라우저가 다운로드를 막으면 **유지**를 선택

## 사용법

### 1. 게임 설정
- 게임을 **"테두리 없는 창"** 모드로 실행하세요. 독점 전체화면에서는 오버레이가 안 보입니다.
- 그래도 안 보이면: 게임 exe 속성 → 호환성 → **"전체 화면 최적화 사용 안 함"**

### 2. 처음 설정 (트레이 아이콘 우클릭 → 설정 열기)
| 항목 | 설명 |
|---|---|
| 선수 이름 | 채팅에 나올 주인공 이름 |
| 소속팀 | 12개 구단 중 선택. 점수판에서 우리 팀이 왼쪽/오른쪽인지 찾는 데 씁니다 |
| 포지션 | 타자 / 투수 / 투타겸업. 투수면 삼진=환호, 피홈런=탄식으로 반응이 뒤집힙니다 |
| 감지 방식 | **자동 하이브리드(권장)**: 화면 OCR 우선, 못 읽을 때만 Gemini Vision |
| 게임 메모리 읽기 (싱글 전용) | 볼카운트·아웃·이닝·타석 결과를 게임에서 직접 읽어 정확도를 높입니다. **온라인 대전 전에는 꼭 끄세요** |
| Gemini API 키 (선택) | Vision 감지와 AI 대사에 사용. 없어도 기본 대사로 동작합니다 |
| 대사 만드는 AI (선택) | Gemini(무료 한도) 또는 DeepSeek(유료, 저렴). DeepSeek은 대사만 만들고 Vision은 Gemini 키로 |
| 비속어 강도 / 채팅 속도 | 취향대로 |

### 3. 채팅창 보기
- **우리 팀 팬** 채팅: 소속팀 색 띠와 배지 (예: 소프트뱅크 = 노란 `SB`)
- **상대 팀 팬** 채팅: 회색 띠와 `상대` 배지
- 말풍선이 밝고 굵을수록 채팅이 달아오른 상태입니다
- 일시정지 메뉴에서는 채팅이 쉽니다

### 4. 트레이 메뉴
- **채팅 창 위치 수정** — 파란 점선 상자를 마우스로 끌어 옮기고 **완료** (또는 Enter/Esc)
- 클릭 통과 켜기/끄기 · 위치 초기화
- 화면 감지 켜기/끄기 · 설정 열기 · 테스트 패널
- **오류·개선 제안 보내기** — 제작자에게 바로 전달됩니다 (진단 정보 첨부 선택 가능, API 키는 보내지 않음)
- **업데이트 확인** — 새 버전이 있으면 받아서 교체 후 다시 켜집니다

### 5. 단축키
| 키 | 동작 |
|---|---|
| `Ctrl+Shift+E` | 채팅 창 위치 수정 (마우스로 드래그) |
| `Ctrl+Shift+방향키` | 채팅 창 이동 |
| `Ctrl+Shift+PageUp / PageDown` | 채팅 창 높이 |
| `Ctrl+Shift+L` | 클릭 통과 켜기/끄기 |
| `Ctrl+Shift+O` | 종료 |

## 게임 메모리 읽기에 대해
- **싱글 경기 전용**입니다. 온라인 대전에서는 켜지 마세요.
- 게임 메모리를 **읽기만** 하고 쓰거나 주입하지 않습니다.
- 게임이 패치돼 버전이 달라지면 자동으로 꺼지고 화면 감지만 사용합니다.
- 주인공 타석은 화면 감지가 처음 한 번 확인한 타순으로 학습합니다.

## 문제 해결
- **오버레이가 안 보임** → 테두리 없는 창 / 전체 화면 최적화 끄기
- **채팅이 안 나옴** → 감지 방식이 켜져 있는지, 게임이 실행 중인지 확인
- **맞은 안타가 친 것처럼 나옴** → 설정에서 포지션과 소속팀 확인 (투타겸업은 소속팀이 꼭 필요)
- **"Gemini 할당량 초과" 배너** → 무료 한도 소진. 다른 키 등록 또는 결제 활성화
- 그 밖의 문제는 트레이 → **오류·개선 제안 보내기**로 알려 주세요
- 설정·로그 폴더: `%APPDATA%\ProspiLiveOverlay` (`core.log`, `update.log`)

### v0.1.1 — 2026-10-01
**새 기능**
- **DeepSeek으로 AI 대사 만들기**: 설정 → AI 반응 → "대사 만드는 AI"에서 DeepSeek 선택 후 키 입력 (유료, platform.deepseek.com 에서 충전 필요). 화면 판단(Vision)은 계속 Gemini 키가 있을 때만 사용
- DeepSeek "키 확인" 버튼: 틀린 키·잔액 부족을 바로 알려 줌 (요금 안 나감)

### v0.1.0 — 2026-09-26
첫 공개 배포입니다. 공개 전 테스트 기간의 개선·수정 내역을 모두 담았습니다.

**새 기능**
- 싱글 경기 전용 **게임 메모리 읽기**: 볼카운트·아웃·이닝·삼진/범타/볼넷/출루를 게임에서 직접 읽음 (읽기 전용, 기본 꺼짐, 게임 버전이 다르면 자동 비활성)
- **채팅 창 위치 수정** 모드: 마우스로 끌어서 옮기기 (`Ctrl+Shift+E`)
- **우리 팀 / 상대 팀 팬 구분**: 팀 색 배지와 띠, 상대 팬의 반대 입장 채팅
- **소속팀 12개 구단 목록 선택**: 점수판 한글·영문·일본어 표기 모두 인식
- 게임 메모리 읽기를 켜면 **홈/원정 팀 번호로 우리 팀 위치를 경기마다 바로 확정** (12개 구단 모두 지원)
- **오류·개선 제안 보내기**: 앱에서 바로 제작자에게 전송
- **자동 업데이트**: 새 버전 알림 → 다운로드·서명 확인 → 교체 후 재시작
- **장면 전용 AI 채팅**: 주인공 타석 결과·득점·끝내기·경기 종료마다 그 순간 상황(이닝·점수·누가 무엇을)을 AI에 알려 우리 팬·상대 팬 채팅을 바로 만듦 (Gemini 키가 있을 때, 없으면 기본 대사)
- **AI 대사 저장**: Gemini가 만든 대사를 상황별(타자/투수 · 이기는/지는/동점)로 PC에 쌓아 두고, API 할당량이 끝나거나 키가 없을 때 기본 대사와 섞어 씀 — 쓸수록 대사가 늘어남
- 새 프로그램 아이콘

**수정**
- 투수(투타겸업)일 때 상대가 친 안타를 주인공이 친 것처럼 반응하던 문제
- 점수판 방향을 반대로 알고 있던 문제 (경기 화면 점수판은 **홈이 왼쪽, 원정이 오른쪽**) — 점수·초말 공수 판단이 뒤집힐 수 있었음
- 화면 글자를 잘못 읽어 이닝이 앞질러(예: 9회에 "14회") 굳던 문제
- 일시정지 화면의 "18회전" 표시를 점수 18:1로 읽어 가짜 득점 채팅이 반복되던 문제
- 일시정지 메뉴의 "자동 고의 사구" 글자를 볼넷으로 인식하던 문제
- 일시정지 중에도 잡담·AI 대사가 계속 올라오던 문제
- 우리 수비 중에 뒤늦게 읽힌 득점으로 "홈 밟았다 가자" 같은 채팅이 나오던 문제 (점수는 두 번 연속 같게 읽혀야 인정, 수비 중엔 조용히 반영)
- 우리 투수가 잡은 삼진에 타자용 비난("배트도 못 내고")이 섞이던 문제, 우리 득점에 말다툼 연출이 붙던 문제
- 타석이 지나고 한참 뒤에 채팅이 나오던 문제 (새 장면이 오면 밀린 반응은 버리고, 8초 넘게 밀린 채팅은 내보내지 않음)
- 경기 후 GAMESET·타석 평가 화면의 글자를 새 사건으로 읽던 문제
- 주인공 타석을 못 알아봐 홈런에도 반응이 없던 문제 (빨리감기가 아닌 직접 플레이한 타석 = 주인공 타석으로 바로 인식, 영문 HOMERUN 화면 인식)
- 빨리 넘긴 반 이닝(예: 홈팀일 때 1회초)까지 "N회초" 채팅을 띄우던 문제
- 내보내기 직전 경기 상황이 바뀐 채팅은 버림 (지난 장면 뒷북 방지)
- 경기 시작 화면이 뜨기도 전에 채팅이 올라오던 문제 (첫 투구 전까지 조용히, 시작되면 "플레이볼" 반응)
- 아무도 선수 탓을 안 했는데 "결과만 보고 선수 탓하네"가 나오던 문제 (말다툼은 비난 → 반박 순서로만)
- 경기 종료·시작 반응에 경기 중 AI 대사("○○ 홈런…")가 섞이던 문제
- 상대 팀 팬 채팅이 거의 안 보이던 문제 (이제 양 팀 팬이 반반)
- 경기가 끝났는데도 채팅이 계속 올라오던 문제 (종료 반응 짧게 한 번 후 멈춤)
- **끝내기** 인식: 9회 이후 말 공격에서 역전·결승점이 나면 끝내기 전용 반응, 상대 팬도 "끝내기 맞았네" 식으로 (경기 끝났는데 "아직 역전 가능" 같은 말 제거)
- 스타플레이어 모드에서 주인공이 안 나오는 구간을 빨리 넘길 때 엉뚱한 이닝·득점 채팅이 쏟아지던 문제 (빨리감기 중엔 쉬고, 끝나면 바뀐 점수만 한 번 요약)
- 같은 대사·같은 AI 대사가 반복되던 문제 (대사 약 80줄 추가, AI 대사는 한 번씩만 사용)

**공개 전 테스트 기간에 들어간 기능**
- 자동 하이브리드 감지 (OCR 우선, 실패 시에만 Gemini Vision) · 투타겸업 포지션
- Gemini AI 대사 (선택), 가상 시청자 성격·말다툼 연출, 채팅 속도 조절
- 반응 풀·프롬프트 봉인, 설정 파일 손상 시 자동 복구, Gemini 키 암호화 저장
